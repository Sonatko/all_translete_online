# Stage 1: Real-Time Audio & Subtitle Translation

Перевод системного звука из игр, YouTube, Discord в реальном времени:
- Лаунчеры запуска: в корне проекта START_EN_RU.bat и START_ZH_RU.bat
- Бинарники и модели: bin/LiveTranslate и bin/nllb_server
- Горячая клавиша: F9 (показать/скрыть субтитры)
- Сквозной клик: двойной клик колёсиком мыши (2x MMB) по субтитрам.
