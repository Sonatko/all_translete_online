# Дневник разработчика (Day 01): Архитектурное исследование и готовые Open-Source решения

**Дата:** 23 октября 2026  
**Тема:** Проектирование системы синхронного перевода системного звука и мгновенного экранного перевода под Windows (PC) без написания кода с нуля.

---

## 1. Постановка задачи и требования пользователя

1. **Реалтайм перевод речи из любого источника (System Audio & Mic)**:
   - Звук из игр, видео, голосовых чатов (Discord, Telegram, браузер).
   - Транскрипция (ASR / STT — Speech-to-Text) на языке оригинала.
   - Мгновенный машинный перевод на русский язык.
   - Прозрачный поверх всех окон оверлей (Always-on-Top Floating Subtitles) с отображением оригинала + перевода + обучающих подсказок.
2. **Мгновенный экранный и текстовый перевод (Screen OCR & Selection Translation)**:
   - Перевод выделенного мышью текста в любой программе по горячей клавише.
   - Перевод произвольной области экрана (скриншот-выделение рамкой) для игр и видео, где текст является картинкой.
3. **Ограничение: No-Code / Ready-Made Repositories**:
   - Пользователь не является программистом.
   - Исключены решения, требующие написания кода с нуля. Приоритет — готовые бинарные сборки (`.exe`, установщики, портативные архивы с GUI).

## 2. Архитектура: Как это устроено "под капотом" в Production

В операционной системе Windows сквозной перевод разделяется на два независимых физических пайплайна (Data Processing Pipelines):

### Пайплайн А: Потоковый перевод звука (Streaming Audio Pipeline)
```
[Звуковая карта / Приложение: Игра, Браузер, Discord]
       │ (Аудиопоток 48/16 kHz PCM)
       ▼
[WASAPI Loopback Capture (Захват звука без виртуальных кабелей)]
       │
       ▼
[VAD: Voice Activity Detection (Фильтр тишины и пауз, напр. Silero VAD)]
       │ (Кусочки аудио с человеческой речью)
       ▼
[ASR Engine: Speech-to-Text (Распознавание речи: Whisper / Faster-Whisper / Windows Live Captions)]
       │ (Текстовая строка оригинала)
       ▼
[MT Engine: Machine Translation (Переводчик: DeepSeek / OpenAI / DeepL / LibreTranslate)]
       │ (Двуязычный текст + грамматический разбор)
       ▼
[Transparent Click-Through Overlay (Прозрачный оверлей над игрой / видео)]
```

### Пайплайн Б: Экранный и буферный перевод (OCR & Text Selection Pipeline)
```
[Экран монитора / Буфер обмена Windows]
       │ (Выделение области мышью Win+Shift+... или Ctrl+C)
       ▼
[OCR Engine: Оптическое распознавание (PaddleOCR / Windows Media OCR / Tesseract)]
       │ (Распознанный сырой текст)
       ▼
[Dictionary & AI Translation + Anki Flashcard Export]
       │
       ▼
[Всплывающее интерактивное окно с толкованием и переводом]
```

## 5. Специализированный обучающий режим (Educational Dual-Subtitles & Word Tips)

По требованию пользователя система должна не просто переводить, а служить тренажером английского языка.

### А. Изоляция английского языка (Acoustic Language Filtering)
**Проблема:** В голосовом чате (Discord, игра) люди общаются на разных языках, либо играет фоновая музыка. Нужно, чтобы система реагировала **только на английскую речь**.  
**Решение «под капотом»:**  
В системной службе Windows Live Captions (`Win + Ctrl + L`) принудительно задается язык источника: `English (United States)` или `English (United Kingdom)`.  
*Физический принцип:* Акустическая модель нейросети (*Acoustic Model Constraint*) в этом режиме сопоставляет звуковой спектр исключительно с английской фонетической матрицей. Речь на русском или других языках отсекается как нерелевантный шум (*Background Murmur Filter*), что исключает появление мусорного текста в субтитрах.

### Б. Обучающий оверлей с микро-подсказками (Educational Prompting)
В приложении **LiveCaptions-Translator** оверлей выводит оригинальный английский текст и ответ переводчика. Чтобы переводчик работал как персональный репетитор, в конфигурации `setting.json` (или через вкладку настроек API) стандартный запрещающий промпт заменяется на обучающий:

```text
As an expert English-to-Russian simultaneous interpreter and language tutor:
1. Translate the spoken English sentence enclosed in 🔤 into clear, natural Russian on the first line.
2. If the sentence contains idioms, phrasal verbs, slang, or non-trivial B2-C2 vocabulary, add a second line starting with '💡' explaining the key word/idiom concisely in Russian (e.g., '💡 cut corners = схалтурить, сэкономить'). If the sentence is trivial (A1-A2), output only the translation.
REMOVE all 🔤 from the output.
```

**Результат на экране в реальном времени:**
```
[EN] We should definitely cut corners to finish before the deadline.
[RU] Нам определенно стоит срезать углы, чтобы успеть до дедлайна.
[💡] cut corners — схалтурить / сэкономить время в ущерб качеству
```

### В. Мгновенное сохранение слов с экрана (Pot-Desktop + Dictionaries)
Для экранного текста (книги, меню игр, статьи) используется **Pot-Desktop**:
1. Выделение слова/фразы мышью или рамкой OCR.
2. Всплывающее окно мгновенно отображает:
   - Фонетическую транскрипцию (IPA) и озвучку произношения.
   - Словарное определение (Cambridge / Oxford).
   - Кнопку сохранения в персональный список слов (с возможностью синхронизации с карточками Anki).

## 6. Опыт реальных пользователей: Как делают люди и где «грабли» (Reddit & Gaming Communities)

Изучение сотен тредов на Reddit (r/languagelearning, r/visualnovels, r/software, r/IndieGaming) показывает чёткую разницу между тем, как новички пытаются всё усложнить, и к чему в итоге приходят опытные пользователи.

### А. Типичные грабли новичков (Как делать НЕ надо)
1. **Попытка нагородить виртуальные кабели (VB-Audio VoiceMeeter):**  
   Новички пытаются перенаправлять звук между программами через виртуальные аудиокабели.  
   *Итог:* Звук в Discord двоится, появляется задержка в 3–5 секунд, при перезагрузке Windows слетают устройства по умолчанию, микрофон перестает работать.
2. **Запуск тяжелого локального Whisper Large во время 3D-игр:**  
   Попытка крутить 10-гигабайтную локальную нейросеть распознавания прямо на игровом ПК.  
   *Итог:* Игра и нейросеть дерутся за видеопамять (VRAM), игра начинает дропать FPS и зависать.

### Б. Проверенный опыт людей (Принцип доказанной простоты — Zero Friction)
Опытные геймеры и люди, изучающие язык, приходят к простому разделению на 2 действия:
1. **Звук на слух (Стримы, Discord, диалоги):**  
   - Используют встроенный системный захват **Live Captions** (`Win + Ctrl + L`) с языком `English`. Он встроен в Windows, потребляет 0% видеокарты и аппаратно отсекает не-английские языки.
   - Сверху подключается легковесная надстройка **LiveCaptions-Translator**, которая выводит субтитры прямо поверх экрана в формате «Английский + Русский + Подсказка».
2. **Непонятный текст на экране (Квесты, меню, записки, статьи):**  
   - Утилита **Pot-Desktop** с одной горячей клавишей. Нажал `F4` -> обвел рамкой нужный фрагмент -> прочитал перевод и объяснение -> нажал `Esc` и продолжил играть.
   - Никаких постоянно маячащих окон и сложных панелей управления.

## 7. Практическая реализация: Раскладка под компактные клавиатуры и воспроизводимость

**Проблема пользователя:** Компактная клавиатура (60% / 65% / TKL) без физического ряда функциональных клавиш `F1–F12`. Использование комбинаций вроде `Fn + F4` в динамичных играх неудобно и приводит к мисскликам.

### А. Эргономичная и безопасная раскладка (Gamer-Safe Hotkeys)
Исключены любые пересечения с WASD-кластером и клавишами способностей (Q, E, R, C, V, Space):
- **`Ctrl + Shift + T`** (*Translate*) — скриншот-OCR перевод выделенной рамкой области экрана (игры, комиксы, видео). Модификаторы зажимаются мизинцем/ребром ладони, исключая случайные нажатия в бою.
- **`Ctrl + Shift + Y`** — мгновенный перевод выделенного мышью текста в любом окне.
- **`Ctrl + Shift + D`** (*Dictionary*) — вызов карточки толкового словаря и списка слов.
- **`Win + Ctrl + L`** — системный переключатель живых субтитров Windows.

## 8. Итоги практического тестирования звука (Day 01 — Milestone Reached)

**Результат:** Захват системного звука из фильма и синхронный перевод на русский язык **успешно заработали** в реальном времени.

### А. Что пошло не так при первом запуске и как это решили:
1. **Баг скрытия окон (LiveCaptions):**  
   Если в стандартных субтитрах Windows (`Win + Ctrl + L`) положение стоит «Над экраном» или «Под экраном», запуск утилиты глушит окно и ломает вывод.
2. **Как правильно (золотое правило для памяти):**  
   В субтитрах Windows в шестерёнке ⚙️ обязательно должен быть выбран пункт:  
   **«Положение -> Накладывается на экран»**.  
   После этого панель Windows закрывается на крестик, и `LiveCaptionsTranslator.exe` запускается штатно в проводнике двумя кликами.

### Б. Почему перевод сейчас простой (без подсказок 💡):
- Для мгновенного теста мы переключили движок на **Google Translate** (он бесплатный и работает без ключей).
- Обычный Google переводит только «слово в слово» и не умеет объяснять контекст.
- Чтобы появились подсказки по идиомам и сложным словам (`💡`), в настройках (шестерёнка ⚙️ слева) нужно переключить движок на **OpenAI / DeepSeek** и вставить ключ. Тогда включится наш обучающий системный промпт.

### В. Как сделать интерфейс красивым и прозрачным (в следующий раз):
- Сейчас на экране открыто **Главное окно** (MainWindow) с рамкой и историей.
- Чтобы превратить его в тонкие прозрачные субтитры поверх игры:
  1. В левом меню нажмите на шестерёнку **⚙️ (Settings)**.
  2. Перейдите в раздел **Overlay Window** (Окно оверлея).
  3. Нажмите кнопку включения оверлея: окно станет прозрачным, без рамок, с настраиваемым шрифтом и прозрачностью фона, пропускающим клики мыши сквозь себя (*Click-Through*).
