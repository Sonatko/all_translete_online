# Stage 2: In-Place Screen OCR & Visual Translation

Экранный перевод с заменой текста на картинке и обучающие подсказки ИИ:
- Лаунчер запуска: в корне проекта START_OVERTRANSLATE.bat
- Бинарники: bin/OverTranslate
- Шаблон настроек: configs/overtranslate/appsettings.template.json
- Горячие клавиши:
  * Ctrl + Alt + A : замена текста на картинке/в игре
  * Ctrl + Alt + S : мониторинг субтитров в реальном времени
  * Ctrl + C + C   : обучающая карточка с разбором (Groq LPU)
