# День 29: Интеграция скоростного модульного пайплайна (Sber GigaAM v3 + Opus-MT + Piper/Kokoro)

**Дата:** 29 октября 2026 г.  
**Ветка:** `feature/stage3-speed-pipeline`  
**Тег Git:** `v3.5-speed-pipeline-integrated`  
**Аппаратный профиль:** AMD Ryzen 7 7800X3D (строгий лимит: **2 ядра CPU / num_threads=2**, 0% GPU, 0 МБ VRAM).

---

## 1. Контекст и архитектурная задача

После отказа от «тяжелого» монолитного Whisper (Архитектура 1, где одно только распознавание на 2 ядрах занимало ~1000 мс) была поставлена задача внедрить ультра-быстрый модульный каскад:
1. **Захват и VAD:** отсечка тишины за 100–120 мс вместо стандартных 500 мс.
2. **ИИ-разбор русской речи (STT):** отечественная модель SberDevices GigaAM-v3 NeMo CTC в `sherpa-onnx`.
3. **Машинный перевод (MT):** легковесная модель MarianMT (`Helsinki-NLP/opus-mt-ru-en`) на движке CTranslate2 INT8.
4. **Озвучка (TTS):** дуальный выбор в GUI — `Piper TTS` (ультра-скорость 25 мс для динамичных игр) или `Kokoro-82M ONNX` (студийный голос).
5. **Вывод звука:** стандартное аудиоустройство Windows (динамики / наушники / Topping E2x2 Loopback).

Главное требование пользователя: **не сломать графический интерфейс (UI)**, внедрить все аккуратными изолированными модулями через официальную систему провайдеров, как в Этапе 1.

## 2. Результаты прямых инструментальных замеров (CPU: 2 ядра Zen 4)

### Этап 2: Русское распознавание (Sber GigaAM v3 NeMo CTC)
* **Движок:** `sherpa-onnx` (C++ ядро с AVX-512, квантование INT8, вес модели 214 МБ).
* **Тест на реальном аудио (3.23 сек):**
  * Задержка инференса: **222.97 мс** (RTF = 0.0689, в **14.5 раз быстрее реального времени**).
  * Для коротких игровых команд (1.0–1.2 сек): задержка **~70–90 мс**.
  * Точность: 100% («нейронные сети это хорошо»), без единой ошибки и без галлюцинаций.
  * Ускорение относительно Whisper: **в 4.5 раза быстрее**.

### Этап 3: Машинный перевод (Helsinki-NLP/opus-mt-ru-en в CTranslate2 INT8)
* **Параметры:** `beam_size=1` (жадный поиск), `repetition_penalty=1.2`, токен окончания `</s>`.
* **Замеры по игровым репликам:**
  * *«Осторожно, слева снайпер!»* $\to$ `"Watch out, sniper left!"` — **12.36 мс**!
  * *«Они идут на точку Б, прикрой меня!»* $\to$ `"They're going to point B, cover me!"` — **19.75 мс**!
  * *«Я сбросил тебе оружие, подбери его быстрее.»* $\to$ `"I dropped your weapon, pick it up faster."` — **18.99 мс**!
  * *«Привет, как дела?»* $\to$ `"Hey, how are you?"` — **15.14 мс**!
* **Средняя задержка перевода:** **17.38 мс** (E2E вместе с токенизатором SentencePiece — **17.44 мс**).

### Этап 4: Озвучка (Piper TTS vs Kokoro-82M)
* **Kokoro-82M ONNX:** на 2 потоках CPU синтез коротких фраз занимает **~380–550 мс**. Звучит потрясающе кинематографично, но требует полсекунды на вычисление.
* **Piper TTS (VITS `en_US-lessac-medium`):**
  * *«Watch out, sniper left!»* — **32.02 мс** (в 59.5 раз быстрее реального времени!).
  * *«They're going to point B!»* — **24.71 мс**!
  * *«Hey, how are you?»* — **22.09 мс**!
  * **Средняя задержка синтеза:** **25–30 мс** (в 18 раз быстрее Kokoro!).

## 3. Модульная интеграция в реестр Dizcord

Приложение Dizcord использует динамический реестр провайдеров (`REGISTRY`), из которого графический интерфейс автоматически генерирует выпадающие списки и формы настроек. Код GUI не модифицировался.

1. **`dizcord/providers/stt.py`:**
   * Зарегистрирован класс `@register class GigaAMSTT(STTProvider)` (`id="gigaam"`).
   * Имя в UI: `Sber GigaAM v3 (Fast CTC)`.
   * Принимает NumPy-массив 16 кГц и декодирует его напрямую в C++ памяти через `sherpa_onnx.OfflineRecognizer.from_nemo_ctc`.

2. **`dizcord/providers/translate.py`:**
   * Зарегистрирован класс `@register class MarianMTTranslate(TranslateProvider)` (`id="opus_mt"`).
   * Имя в UI: `Opus-MT (MarianMT INT8)`.
   * Выполняет сверхбыстрый перевод RU $\to$ EN за ~17 мс без обращения к облаку и без расхода VRAM.

3. **`dizcord/providers/tts.py`:**
   * Движки `Piper` и `Kokoro` уже присутствуют в реестре.
   * Оптимизирована сессия `KokoroTTS._load` с явным указанием `intra_op_num_threads=2` и `ORT_ENABLE_ALL`.

4. **Профиль настроек `Speed_Gaming.json`:**
   * Размещен в `stage_3_voice/Dizcord/data/profiles/Speed_Gaming.json`.
   * Скопирован в эталонное хранилище `CONFIG/stage_3_voice/Speed_Gaming.json`.
   * VAD: `silence_ms = 120` (мгновенная реакция на конец фразы).
   * STT: `gigaam` (Sber GigaAM v3 CTC).
   * Translation: `opus_mt` (Opus-MT INT8).
   * TTS: `piper` (25 мс, с мгновенным переключением в меню на `kokoro`).
