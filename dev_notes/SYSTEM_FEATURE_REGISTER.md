# Реестр реализованных возможностей и карта регрессионного контроля (Stage 1)

> **Статус документа:** Живой инженерный реестр (The Living Feature Register).  
> **Цель:** Исключить регрессии («сломали то, что уже работало») и предоставить чёткую карту управления всеми компонентами системы.

---

## 1. Золотая схема управления (The Golden Control Scheme)

| Элемент управления | Физическое действие | Что делает в системе | Где прописано в коде |
| :--- | :--- | :--- | :--- |
| **Мастер-хоткей `F9`** | Нажатие клавиши `F9` в любой точке Windows (глобальный хук) | **Синхронный триггер:**<br>1) Если субтитры выключены/пауза → включает субтитры и запускает захват звука (RUN).<br>2) Если субтитры включены → скрывает субтитры и ставит движок на паузу (PAUSE). | `stage_1_audio/LiveTranslate/main.py` (`_F9_HOTKEY_ID`) |
| **Сквозной клик баннера субтитров (Click-through)** | 1) **2x MMB** (двойной клик колёсиком мыши по баннеру субтитров)<br>2) Галочка `Click-through` на темной панели | Переключает режим `WS_EX_TRANSPARENT`.<br>- **Включен:** Мышь пролетает сквозь текст на экран игры/видео.<br>- **Выключен:** Баннер можно перемещать колёсиком мыши.<br>**Синхронизация:** Галочка на панели и состояние баннера меняются одновременно! | `subtitle_window.py` (`mouseDoubleClickEvent`) + `main.py` (`on_toggle_subwin_ct`) |
| **Перемещение баннера субтитров** | Зажатие колёсика мыши (MMB Drag) | Перемещение окна с субтитрами по экрану. Координаты автоматически сохраняются в `user_settings.json`. Левая кнопка мыши (LMB) свободна. | `subtitle_window.py` (`mouseMoveEvent`) |
| **Выбор языка перевода** | Выпадающий список `Target Language` на темной панели | **Главный селектор:**<br>- `Target: en` (равен аудио) → чистый английский ASR белым цветом, задержка 50 мс, переводчик не вызывается.<br>- `Target: ru` → английский ASR + желтый русский перевод NLLB-200. | `main.py` (`_on_target_language_changed`) |
| **Альфа-поверхность DWM** | Фоновый рендеринг баннера | Заливка `Alpha = 1/255` гарантирует, что Windows видит баннер субтитров для кликов колёсика даже при 0% непрозрачности фона. | `subtitle_window.py` (`paintEvent`) |

## 2. Архитектурные инварианты (Что нельзя нарушать)

1. **Инвариант сохранности Git (The Zero-Loss Invariant):**
   * Все рабочие файлы исходного кода `stage_1_audio/LiveTranslate/*.py` теперь отслеживаются напрямую в Git.
   * Тяжёлые папки (`.venv/`, `models/`, `logs/`) исключены в `.gitignore`.
   * Любое изменение в коде фиксируется через `git status` и `git commit`.

2. **Инвариант отсутствия внешних загрузок (Zero-Download Gate):**
   * Модели `sherpa-onnx` (`sensevoice`, `parakeet`) проверяются физически на диске в `model_manager.py`.
   * Модель `NLLB-200` работает локально в процессе (`nllb_engine.py`) без HTTP-серверов.
   * Запуск никогда не триггерит скачивание сторонних моделей с HuggingFace/ModelScope.

3. **Инвариант чистого запуска Windows:**
   * Запуск через `START.bat` вызывает `pythonw.exe` напрямую.
   * Консольное окно лаунчера закрывается через 4 секунды. Никаких черных висящих окон CMD на экране.

## 3. Чеклист 2-минутной проверки (Smoke Test Checklist)

Перед сдачей любого изменения обязательно выполнить:

1. **Автоматический тест компонентов:**
   ```powershell
   stage_1_audio\.venv\Scripts\python.exe tests\test_stage1_smoke.py
   ```
   *Критерий успеха:* Все 5 блоков возвращают `[PASS]`.

2. **Быстрый ручной тест в интерфейсе:**
   - Запустить `START.bat`.
   - Нажать `F9`: субтитры скрываются и процесс переходит в Pause; повторное `F9`: субтитры появляются и процесс возобновляется.
   - Поставить галочку `Click-through` на темной панели: субтитры пропускают клики мыши.
   - Сделать 2x MMB по субтитрам: галочка на панели мгновенно снимается.
   - Зажать MMB на субтитрах: субтитры перетаскиваются по экрану.
   - Запустить `STOP.bat`: все процессы завершаются без ошибок.
