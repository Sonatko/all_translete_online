# Дневник разработчика (Day 02): Реализация пайплайна перевода системного звука и кино-субтитров

**Дата:** 24 октября 2026  
**Тема:** Развёртывание, тонкая настройка и адаптация автономной системы живого перевода LiveTranslate под задачи изучения английского языка (CEFR A1–A2) на Windows 11 с GPU NVIDIA GeForce RTX 5070.

---

## 1. Контекст и аппаратное обеспечение

* **ОС:** Windows 11 Pro
* **Графический ускоритель (GPU):** NVIDIA GeForce RTX 5070 (Архитектура Blackwell, sm_120, Compute Capability 12.0)
* **CUDA / Драйвер:** CUDA 12.8 (драйвер 572.x)
* **Аудиокарта:** Внешний USB-аудиоинтерфейс `Playback 1/2 (6- E2x2 OTG)`
* **Целевое ПО:** [TheDeathDragon/LiveTranslate](https://github.com/TheDeathDragon/LiveTranslate)

---

## 2. Развёртывание окружения и решение проблем совместимости с RTX 5070

### Архитектурный вызов
Архитектура NVIDIA Blackwell (RTX 50-я серия) требует актуальных бинарных сборщиков PyTorch с поддержкой Compute 12.0 (CUDA 12.8). Стандартный PyTorch с CUDA 11.8/12.1 завершался бы ошибкой несовместимости ядра (`no kernel image is available for execution on the device`).

### Реализация
1. Окружение развёрнуто в `bin/LiveTranslate/.venv` с помощью пакетного менеджера `uv`.
2. Установлен официальный PyTorch с поддержкой CUDA 12.8:
   `--extra-index-url https://download.pytorch.org/whl/cu128`
3. Проверена доступность тензорных ядер и VRAM: 12 ГБ видеопамяти полностью доступны для локального инференса.

## 3. Сквозной пайплайн обработки звука (Audio -> ASR -> Translation -> Render)

```
[Системный звук: YouTube / Игра / Discord]
       │ (WASAPI Loopback Capture через E2x2 OTG)
       ▼
[Silero VAD (Voice Activity Detector)]
       │ (Порог активации 0.3, фиксация пауз от 0.8с)
       ▼
[ASR: FunASR SenseVoice Small (локально на CUDA 12.8)]
       │ (Задержка распознавания: ~60–90 мс)
       ▼
[LLM: Groq Cloud API (openai/gpt-oss-20b)]
       │ (Инференс на LPU: ~500–800 мс)
       ▼
[Subtitle Window: Кинематографический прозрачный оверлей]
       │ (Английский: 28pt Bold #FFD700 + Черный Outline 3px)
       │ (Русский: 20pt Regular #A0B0C0 + Черный Outline 2px)
       ▼
[Экран пользователя (Полноэкранный просмотр / Click-Through)]
```

## 4. Настройка ASR и устранение ошибок API перевода

### ASR (Распознавание речи)
* Выбрана модель **FunASR SenseVoice Small** (`FunAudioLLM/SenseVoiceSmall`, объём кэша ~1.76 ГБ).
* Демонстрирует феноменальную скорость (~60–90 мс на реплику) при высоком качестве распознавания английской речи со знаками препинания.

### LLM Translation (Groq Cloud API)
В ходе интеграции Groq API были выявлены и устранены следующие ошибки провайдеров:
1. **Ошибка 404 (`llama-3.3-70b-versatile not found`):**
   * *Причина:* Groq обновил идентификаторы моделей.
   * *Решение:* Переключено на стабильную и сверхбыструю модель `openai/gpt-oss-20b` (до 1000 токенов/сек).
2. **Ошибка 400 (`property 'enable_thinking' is unsupported`):**
   * *Причина:* Попытка отправить флаг рассуждений в неподдерживаемый эндпоинт.
   * *Решение:* Параметр `thinking_style` переведён в режим `off` (не отправлять параметры размышлений).
3. **Предупреждение о пустом ответе (`Empty completion but 256 tokens used`):**
   * *Решение:* `max_tokens` увеличен до 1024.

## 5. Психолингвистическое оформление субтитров (Dual Subtitle Ergonomics)

Опираясь на исследования айтрекинга (*Cambridge University, 2026: Hearing once, reading twice*) и теорию двойного кодирования Пайвио:

1. **Верхняя строка (English - L2 Target):**
   * Доминирующий визуальный фокус: **28 pt**, цвет **`#FFD700`** (теплый золотисто-желтый), черная обводка **3 px**.
   * Зрачок фиксируется на оригинале одновременно со звуком в наушниках.
2. **Нижняя строка (Russian - L1 Translation):**
   * Вспомогательный слой (страховка): **20 pt**, цвет **`#A0B0C0`** (приглушенный серо-голубой), черная обводка **2 px**.
   * Не перетягивает на себя внимание, считывается периферическим зрением только при затруднении.
3. **Автоскрытие (*Auto-hide*):**
   * Тайм-аут: `3–5 сек` тишины.
   * Анимация: `Fade` (плавное растворение). Субтитры не засоряют экран при паузах.

## 6. Проектирование системного промпта для уровня CEFR A1–A2

### Проблема «Тавтологического толкования»
При наивном промпте («всегда выдели 1 слово и объясни его») модель на элементарную фразу *«My name is Mark»* выдавала:
`Меня зовут Марк. 💡 name = имя (название, которое присваивается человеку).`
Это перегружает зрительное поле мусором.

### Финальный профессиональный промпт для A1–A2
Внедрён фильтр тривиальности (*Significance Filter*) и строгие негативные ограничения (*Negative Constraints*):

```text
You are an expert English-to-Russian subtitle translator for an A1-A2 English learner.
Translate the speech into natural, concise Russian.

RULES:
1. Output the natural Russian translation first.
2. If and ONLY IF the sentence contains a useful phrasal verb, idiom, or vocabulary word that an A1 beginner might struggle with, append:
💡 <word/phrase> = <1-2 Russian translation equivalents>
3. STRICT NEGATIVE RULES:
- NEVER explain elementary words (e.g. I, you, my, name, is, the, this, what, yes, no, good).
- If the sentence is trivial (e.g. "My name is Mark"), output ONLY the translation with NO hints!
- NEVER write definitions or text in parentheses. ONLY direct translations.
- Maximum 1 hint per sentence, under 5 words.
```

## 7. Встраивание мастер-клавиши (Global Hotkey F9: Sub + Run / Stop)

### Задача
Объединить показ субтитров и работу транскрипции/перевода в единый цикл:
* Когда субтитры не нужны — не только скрывать их с экрана, но и **останавливать инференс** (`Pause`), чтобы не расходовать токены Groq и не нагружать GPU.
* Когда субтитры нужны — одной кнопкой **показывать их и запускать захват/перевод** (`Run`).

### Реализация
* Клавиша **`F9`** (а также кнопка **`Sub`** на оверлее) теперь работает как синхронный мастер-переключатель:
  * **ВКЛ (ON):** Показывает окно кино-субтитров (`Sub`) **И** запускает транскрипцию звука (`Run`). Кнопка `Run` на оверлее автоматически переходит в режим активной работы.
  * **ВЫКЛ (OFF):** Скрывает окно субтитров **И** ставит транскрипцию на паузу (`Pause`). Поток звука и запросы к LLM немедленно засыпают.
* Использован нативный `RegisterHotKey` Windows API с перехватом через `QAbstractNativeEventFilter` на главном GUI-потоке Qt (0% нагрузки на процессор).

## 8. Эргономика перемещения: переключение «Click-through» двойным кликом колёсика

### Суть решения
Галочка **`Click-through`** (Клик насквозь):
* **ВКЛЮЧЕНА:** клики проходят насквозь в видео/игру, перетаскивание колёсиком отключено.
* **ВЫКЛЮЧЕНА:** окно принимает клики, его можно свободно перетаскивать зажатием колёсика мыши.

### Реализация
Вместо ручного захода в меню настроек внедрён глобальный хук мыши (`WH_MOUSE_LL`):
1. **Двойной клик колёсиком (Middle Double-Click) над субтитрами:**
   * Мгновенно переключает состояние **`Click-through`** (ВКЛ / ВЫКЛ).
   * Автоматически синхронизирует чекбокс в панели управления и иконку в трее.
2. **Сценарий использования:**
   * Субтитры прозрачны для кликов -> захотели сдвинуть -> сделали двойной клик колёсиком над ними -> `Click-through` выключился -> зажали колёсико и перетащили -> снова двойной клик колёсиком -> `Click-through` включился, субтитры заблокированы на новом месте!
