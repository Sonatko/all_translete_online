# Дневник разработки: День 24. Утверждение Архитектуры 1 и Мастер-план Stage 3

## 1. Контекст решения
После глубокого анализа условий работы (компьютер на работе с процессором **AMD Ryzen Zen 4** с инструкциями **AVX-512** и встроенной графикой **Radeon iGPU** через **Vulkan**, а также опциональная внешняя карта **RTX 5070** дома через райзер) была утверждена **Архитектура 1: «Vulkan / C++ Монолит»**.

### Выбранные ключевые компоненты:
1. **Звуковой ввод/вывод:** Микрофон *Behringer XM8500* -> Звуковая карта *Topping Professional E2x2 OTG* (физический вход `IN 1` -> аппаратный канал `Topping Loopback Out`). Никаких виртуальных кабелей (VB-Cable).
2. **VAD:** *Silero VAD v5 (ONNX)* с адаптивным порогом фиксации конца фразы 250 мс.
3. **Прямой перевод речи (ASR + MT в один шаг):** *whisper.cpp* с бэкендом **Vulkan** на iGPU / **AVX-512** на CPU. Квантование `q5_0`, `task="translate"`, жадный поиск `beam_size=1`, ограничение длины `max_tokens=64`. Время инференса: **~120–140 мс**.
4. **Нейросинтез речи (TTS):** *Kokoro-82M ONNX* на процессоре Ryzen Zen 4. Студийные английские голоса дикторов (`af_sky`, `af_bella`, `am_adam`), время инференса 2-секундного отрезка: **~100–110 мс**.
5. **Открытая основа:** Адаптация многопоточного каркаса *LiveLingo* (Windows) с полной изоляцией от *LiveTranslate* (Этап 1).

### Бюджет задержки (Latency Budget):
* **Рабочее место (CPU/iGPU):** 250 мс (VAD) + 130 мс (Whisper) + 110 мс (Kokoro) = **~490 мс**.
* **Дома с RTX 5070:** 250 мс (VAD) + 50 мс (Whisper) + 50 мс (Kokoro) = **~350 мс**.
