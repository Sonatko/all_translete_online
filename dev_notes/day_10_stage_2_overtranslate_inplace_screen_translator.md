# Дневник разработки: День 10 (Этап 2: OverTranslate — замена текста прямо на экране и обучалка)

## 1. Задача и выбранное решение
Для Этапа 2 (перевод экранного текста, окон, комиксов и игр) пользователь выбрал подход **«In-Place Screen Translation» (эффект Google Lens)** — когда перевод накладывается прямо на место оригинального иностранного текста, а также требуется обучающий режим разбора (словарь, грамматика, транскрипция/пиньинь).

Выбран флагманский проект: **[Hon-Lu/OverTranslate](https://github.com/Hon-Lu/OverTranslate)** (C# .NET 8, лицензия MIT, RapidOcrNet / PP-OCRv6 ONNX).

---

## 2. Инженерная реализация и конфигурация

### 2.1. Установка и интеграция
- Загружен и распакован релиз `OverTranslate-win-Portable.zip` в каталог `bin/OverTranslate/current/`.
- Добавлен процесс `OverTranslate` в `STOP_ALL.bat` для чистого завершения одной кнопкой.
- Создан 1-клик лаунчер: `START_OVERTRANSLATE.bat`.

### 2.2. Настройка шлюза перевода, исправление ошибки 402 и обучалка
- Из локального хранилища `~/.secrets` безопасно извлечён ключ **OpenRouter** (без утечки в git или консоль).
- **Разбор ошибки 402 (Payment Required):**
  - При попытке перевода платной моделью (`google/gemini-2.5-flash`) OpenRouter возвращал: `This request requires more credits, or fewer max_tokens. You requested up to 65535 tokens, but can only afford 5804`.
  - Причина: класс `OpenAiChatTranslator` в OverTranslate не передаёт параметр `max_tokens` в JSON-запросе, поэтому OpenRouter резервирует стоимость полного окна модели (65 535 токенов). Если на балансе меньше кредитов, запрос блокируется.
- **Исследование пула бесплатных моделей и лимитов ключа:**
  - Через эндпоинт `https://openrouter.ai/api/v1/auth/key` получены реальные квоты аккаунта: **1000 бесплатных запросов в сутки** (`free_model_daily_requests.limit = 1000`). Лимит единый для всех бесплатных моделей.
  - Через эндпоинт `https://openrouter.ai/api/v1/models` проверен список из 17 активных бесплатных моделей (Google Gemma 31B, NVIDIA Nemotron 1M context, Liquid AI и др.).
- **Конфигурация через виртуальный роутер `openrouter/free`:**
  - В `%APPDATA%\OverTranslate\appsettings.json` установлен единственный профиль:
    - **Название:** `OpenRouter Auto-Free (Авто-выбор без лимитов)`
    - **Модель:** `openrouter/free`
    - **Стоимость токенов:** ровно $0.00 (проверка баланса отключена, ошибка 402 невозможна).
    - **Отказоустойчивость (Fallback):** если одна бесплатная модель перегружена или возвращает ошибку, OpenRouter за доли секунды сам переключает запрос на следующую рабочую бесплатную модель. Пользователю не требуется переключать профили руками.
    - **Обучающий системный промпт:** сохранён и внедрён во все типы запросов:
      - Прямой перевод выделенного текста.
      - 📖 Словарная форма / транскрипция или пиньинь.
      - 💡 Грамматический нюанс и контекст.
      - 📝 Пример употребления.

### 2.2. Переход на нативные сверхбыстрые словари и режим обучения (Zero-Lag)
- **Отказ от внешних LLM-шлюзов (OpenRouter):**
  - Облачные LLM на бесплатных тарифах помещаются в фоновые очереди (`Spot Queue`) с задержками по 10–25 секунд и периодическими кодами 429 при динамичной игре.
  - Настройки OpenRouter (`OpenAiApiKey`, `OpenAiBaseUrl`) полностью очищены.
- **Включение нативных обучающих движков OverTranslate:**
  - Основной движок мгновенного перевода: **`GoogleWeb`** (время отклика: 0.2–0.4 секунды, без ключей, без ограничений).
  - Мониторинг субтитров в играх: **`Microsoft`** в параллельном режиме сравнения:
    - **`Realtime.CompareDisplay = true`** — на экране выводятся одновременно оригинальный текст (английский/китайский) и русский перевод друг над другом для закрепления ассоциаций.
  - Всплывающий обучающий словарь **`QuickLookup`**:
    - **`BilingualEnabled = true`** (`EN-US` + `RU`) — показывает транскрипцию, произношение, часть речи, категориальные значения и контекстные примеры употребления из академических словарей (Google, Bing, Youdao).

### 2.3. Горячие клавиши управления
- **`Ctrl + Alt + A`** — Интерактивный захват области экрана (перевод заменяется прямо на картинке за 0.3 секунды; по каждому слову можно кликнуть для вызова словарной карточки).
- **`Ctrl + Alt + S`** — Непрерывный мониторинг зоны экрана в реальном времени с параллельным показом оригинала и перевода (`CompareDisplay`).
- **`Ctrl + C + C`** — Мгновенный вызов двуязычной словарной карточки по выделенному слову.
- **`Ctrl + Alt + W`** — Вызов главного окна настроек.
