# Дневник разработки: День 11. Анализ инцидента при реорганизации проекта и полное восстановление

## 1. Описание инцидента (Post-Mortem / Что сломалось и потерялось при чистке)

При реорганизации файловой структуры проекта под 4-стадийную архитектуру (`stage_1_audio`, `stage_2_screen`, `stage_3_anki`, `stage_4_voice`) и переносе вспомогательных скриптов в `archive/` возник масштабный сбой рабочего окружения:

### Что конкретно сломалось и почему:
1. **Потеря пользовательских конфигураций (`user_settings.json` / `user_settings_zh.json`):**
   * **Причина:** В файле `.gitignore` апстрим-репозитория LiveTranslate стояла строка `user_settings.json`. Из-за этого Git не отслеживал локальный файл настроек. При переносе папок и переключении лаунчеров конфигурация была сброшена на дефолтные значения.
   * **Следствие:** Слетели калиброванные параметры VAD (отсечки тишины), привязка к аудиокарте E2x2 OTG, модель Whisper Medium, сервер NLLB 1.3B, а также персональная визуальная стилизация субтитров (золотистый цвет `#ffd54f`, размеры шрифтов, отступы).

2. **Сброс тюнинга модели Whisper Medium в `asr_engine.py`:**
   * **Причина:** Файл движка распознавания был перезаписан дефолтной версией без инженерных правок.
   * **Следствие:** Пропали параметры лучевого поиска (`beam_size=2`, `best_of=2`, `temperature=0.0`), фильтр галлюцинаций тишины (`noise_hallucinations`), затравка стандартного путунхуа `initial_prompt="以下是普通话的句子。"` и беспробельная склейка китайских иероглифов.

3. **Сбой хуков перехвата мыши (64-bit ctypes Overflow):**
   * **Причина:** В 64-битной Windows типы `ctypes.wintypes.LPARAM` транслируются как 32-битный `c_long`. Указатели на структуры мыши `WH_MOUSE_LL` вызывали `OverflowError: int too long to convert`.
   * **Следствие:** Вылет хука мыши, из-за чего окно субтитров переставало перетаскиваться или блокировало клики.

4. **Ошибка переключения прозрачности (`AttributeError`):**
   * **Причина:** В классе `SubtitleWindow` отсутствовало объявление сигнала `click_through_toggled = pyqtSignal(bool)`.
   * **Следствие:** При попытке двойного клика колёсиком мыши (`2x MMB`) программа падала с необработанным исключением.

5. **Дублирование текста в субтитрах («Thank you» / «Thank you»):**
   * **Причина:** При парсинге секции `subtitle_mode.lines` код окна ожидал явные ключи `"type": "original"` и `"type": "translation"`. При их отсутствии обе строки рендерили оригинальный английский текст, игнорируя готовый русский перевод от NLLB.

6. **Множественные зависшие консольные окна (CMD / Python):**
   * **Причина:** Повторные запуски лаунчеров без предварительного завершения фоновых процессов `pythonw.exe` приводили к накоплению зомби-процессов и конфликту портов (8080).

## 2. Проведённые восстановительные работы

Все утерянные данные были пошагово восстановлены из неизменяемых журналов сессий IDE (`transcript_full.jsonl`):

1. **Восстановление аутентичного конфига (Шаг 6134 / Ночная сессия):**
   * **Стилизация UI:** Ширина 1200px, скругление 10px, прозрачность фона 153, межстрочный интервал 6px.
   * **Строка 1 (Оригинал):** Чистый белый цвет `#ffffff`, размер 22px, шрифт `Segoe UI` (или `Microsoft YaHei` для китайского), выравнивание по левому краю (`left`).
   * **Строка 2 (Перевод):** Теплый золотистый цвет `#ffd54f`, размер 20px, выравнивание по левому краю (`left`).
   * **Координаты на мониторе:** `X: 685, Y: 47` (оверлей `1514x590`).
   * **Аудиокарта:** `"Playback 1/2 (6- E2x2 OTG)"` [Loopback].

2. **Восстановление связки Whisper Medium + NLLB-200 1.3B (Шаг 6325):**
   * **VAD:** `silero`, порог `vad_threshold = 0.35`, пауза `silence_duration = 0.42s`, максимальная длина `max_speech_duration = 7.0s`, паддинг `whisper_pad_seconds = 0.3s`.
   * **NLLB-200 1.3B:** CTranslate2 на CUDA (`int8_float16`), `beam_size = 4`, `length_penalty = 1.0`, `repetition_penalty = 1.1`, `max_decoding_length = 64`.
   * **Whisper Medium:** CTranslate2 на CUDA (`int8_float16`), `beam_size = 2`, `best_of = 2`, `temperature = 0.0`.

3. **Исправление кода окна субтитров:**
   * В `subtitle_window.py` внедрены 64-битные типы `c_size_t` и `c_void_p` для функции `CallNextHookEx`.
   * Объявлен сигнал `click_through_toggled = pyqtSignal(bool)` и синхронизирован с трей-меню и чекбоксом в панели управления.
   * Сохранена невидимая подложка `QColor(0, 0, 0, 1)` в `paintEvent` для бесперебойного DWM-хэширования мыши.

## 3. Защитные инженерные меры от будущих сбоев (Hardening)

Чтобы исключить повторение инцидента, реализованы следующие архитектурные решения:

1. **Создана независимая директория `CONFIG/` в корне проекта:**
   * `CONFIG/stage_1_audio/user_settings.json`
   * `CONFIG/stage_1_audio/user_settings_zh.json`
   * `CONFIG/stage_2_screen/appsettings.template.json`
   * Папка полностью отслеживается Git (`!CONFIG/` в корневом `.gitignore`).

2. **Снято игнорирование настроек в апстриме:**
   * Из `stage_1_audio/LiveTranslate/.gitignore` удалена строка `user_settings.json`.
   * Файлы `user_settings.json` и `user_settings_zh.json` закоммичены напрямую в Git-репозиторий субмодуля LiveTranslate.

3. **Фиксация коммитов:**
   * Коммит субмодуля: `60555b1` (*feat(settings): track active user_settings and user_settings_zh directly in git*)
   * Коммит корневого репозитория: `2f34bd3` (*feat(config): isolate all configs into dedicated CONFIG directory and persist Whisper Medium and 1.3B tuning*)

4. **Правило чистки проекта:**
   * Никакие файлы и папки не должны перемещаться или удаляться без предварительной сверки со статусом Git и проверки содержимого локальных конфигураций.
